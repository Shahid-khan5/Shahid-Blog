## Selected projects

### AgricultureAI, AUP Assistant

[agricultureai.shahidkhan.dev](https://agricultureai.shahidkhan.dev) · 2026

An AI assistant for students of The University of Agriculture, Peshawar. It answers questions about fees, admissions, merit lists, exams, hostels and staff, using only the official site, aup.edu.pk. Every answer links to the pages and PDFs it used.

- Agent with 4 tools (search, read page, list notices, read document) and 23 skills that load only when a question needs them.
- Search index of about 1,060 crawled pages, including all 311 staff profiles.
- Reads scanned PDFs with Claude Haiku, once per document.
- Privacy rules in the agent: it never shares staff phone numbers or emails.
- Public spend counter, so students see what the service costs to run.
- Stack: Next.js 16, React 19, eve, Vercel AI SDK, Claude, Tailwind CSS, Drizzle, Neon Postgres, Upstash Redis, PostHog.
